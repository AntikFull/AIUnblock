# AI Unblock

Лёгкое Android-приложение без root, которое автоматически выбирает рабочие
DNS/GeoHide-серверы для поддерживаемых AI-приложений.

## Возможности

- одна кнопка включения и выключения;
- пользователь может добавить любое запускаемое приложение в список GeoHide;
- Material 3 Expressive;
- `VpnService` применяется только к установленным целевым пакетам:
  - `com.google.android.apps.bard`;
  - `com.google.android.googlequicksearchbox`;
  - `com.google.android.apps.labs.language.tailwind`;
  - `com.openai.chatgpt`;
  - `com.anthropic.claude`;
- TLS не расшифровывается: анализируется только SNI из `ClientHello`;
- подходящие соединения TCP/443 направляются на соответствующий шлюз с сохранением исходного TLS-потока;
- прочие TCP-соединения и UDP, кроме UDP/443, идут напрямую;
- UDP/443 блокируется, чтобы исключить QUIC;
- IPv4 и IPv6 захватываются VPN, исходящие сокеты защищаются через `VpnService.protect()`;
- DNS/GeoHide-серверы автоматически проверяются при включении и затем каждые 30 минут;
- после первого включения запрашивается исключение из оптимизации батареи;
- рабочие адреса выбираются раздельно для Gemini/Google, NotebookLM, ChatGPT и Claude;
- последний успешный выбор сохраняется и используется при следующем запуске;
- локальный SOCKS5-релей требует случайные учётные данные, существующие только в памяти процесса;
- нет рекламы, аналитики, регистрации и сбора содержимого трафика.

## Маршрутизация

- Gemini/Google, NotebookLM, ChatGPT и Claude используют независимый автоматический
  выбор из встроенного пула совместимых DNS/GeoHide-серверов;
- перед проверкой выполняется DNS-авторизация внешнего IP у совместимых Smart DNS;
- при недоступности текущего адреса выбирается первый сервер, прошедший проверку TLS,
  сертификата и HTTP-ответа для соответствующего сервиса;
- домены, не совпавшие с правилами, пропускаются напрямую.
- база GeoHide объединяет 304 домена из списка провайдера и 199 точечных
  записей Smart DNS; блокирующие записи `0.0.0.0` исключены;
- точечные записи Smart DNS подменяются в DNS-ответах, поэтому поддерживаются
  игровые TCP/UDP-подключения не только на порту 443;
- для пользовательских приложений VPN перехватывает только их трафик:
  поддерживаемые домены идут через GeoHide, остальные соединения — напрямую.

Правила находятся в `app/src/main/java/ru/ecubz/aiunblock/RoutingRules.kt`,
а подбор шлюзов — в `GatewaySelector.kt`.

## Сборка

Требования:

- Android SDK: `E:\AndroidSDK`;
- Android SDK Platform 37;
- Android NDK `28.1.13356709`;
- JDK 17 или новее.

Release APK собирается как universal для `arm64-v8a` и `armeabi-v7a`.

Из корня проекта:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease --no-configuration-cache
```

Результаты:

- устанавливаемая debug-сборка: `app/build/outputs/apk/debug/app-debug.apk`;
- release-сборка без подписи: `app/build/outputs/apk/release/app-release-unsigned.apk`.

Для публикации release APK необходимо настроить собственный закрытый ключ подписи. Ключи и пароли не должны храниться в репозитории.

## Ограничения

- Android допускает только один активный `VpnService`;
- при первом запуске требуется системное согласие пользователя;
- во время работы Android показывает обязательное foreground-уведомление;
- приложение не изменяет локаль сторонних приложений;
- работоспособность шлюзов и полная маршрутизация должны проверяться на физическом устройстве и в разных сетях.
